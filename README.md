## 📚 How I Approach Learning

I believe the best way to learn DevOps is through **building, documenting, testing, and troubleshooting**.

For every project, I aim to answer five important questions:

1. **The Problem:** What problem does this project solve?
2. **The Architecture:** Why were these technologies and tools selected?
3. **The Implementation:** How can someone deploy or reproduce the project?
4. **The Troubleshooting:** What went wrong, and how did I diagnose and resolve it?
5. **The Improvements:** What would I change before deploying a similar solution in production?

My goal is not simply to complete tutorials, but to understand how technologies work together in real-world environments.
